**Audit date:** 2026-08-18
**Method:** static source audit of `apps/web` — no live crawl. Every finding is grounded in a file and line in this repo.

## 2. Canonical tags

`SEO.tsx:32-33` builds `canonical` from the optional `url` prop and **falls back to the site root when omitted**:

```ts
const cleanPath = url ? url.replace(/\/+$/, '') : '';
const currentUrl = cleanPath ? `${siteUrl}${cleanPath}/` : `${siteUrl}/`;
```

Ten gated surfaces omit `url`, so each emits `rel=canonical → https://www.snaprecorder.org/` alongside its own `noindex`. Every one of the 48 public routes does pass `url`, so **no indexable page is mis-canonicalised**.

Impact is contained by `noindex`, but conflicting `noindex` + canonical-to-homepage is exactly the signal pair Google documents as "do not do" — it can attach the `noindex` to the canonical target.

**Fix:** make `url` required, or fall back to `useLocation().pathname`.

## 9. Performance-related SEO

| Finding | Detail | Severity |
|---|---|---|
| **6.4 MB OG image preloaded** | `index.html:22` — `<link rel="preload" as="image" href="/og-image.png">` fires at **highest priority on all 48 routes**, for an image no route displays. It will win the network against the real LCP element. Also exceeds X/Twitter's 5 MB and WhatsApp's ~600 KB crawler caps, so social previews silently fail. | Critical |
| **Single 1.8 MB JS chunk** | `dist/assets/index-*.js` = 1.8 MB raw + 112 KB CSS. `vite.config.ts` has **no `build.rollupOptions.manualChunks`** — only `Editor` (330 KB) and `VideoEditorPage` (71 KB) are split. Marketing visitors download supabase-js, TanStack Query, react-router and iconify to read a blog post. | Warning |
| **Unconditional AdSense in `<head>`** | `index.html:31` — third-party script on every marketing and blog page, loaded **before** `CookieConsent` resolves. INP + LCP cost sitewide. | Warning |

There is no CI workflow for the web build — only `indexnow.yml`. If Cloudflare Pages runs `build` rather than `build:prerender`, all 48 routes serve the generic `index.html` title/description to any non-JS crawler and every per-page tag above is invisible. **Verify the Pages build command.** | Warning |
| Render-blocking resources | **None.** Material Symbols uses `preload`+`onload` swap with a `<noscript>` fallback; UI fonts are self-hosted and JS-imported. | — |
| No asset `Cache-Control` | `_headers` sets security headers only — no `immutable` policy for hashed `/assets/*`. | Info |
