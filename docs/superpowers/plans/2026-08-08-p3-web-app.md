# P3 Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current dashboard shell and its seven surfaces with the prototype's rail-and-top-bar application, covering Home (6 states), Library (9 states), Projects, Shared, Analytics and Settings — desktop through 390px.

**Architecture:** `MainLayout` becomes a rail + top bar shell built on the P1 `AppRail`, with the responsive ladder driven by a single `useBreakpoint` hook rather than scattered Tailwind variants. Every capture renders through `CapturePlate` or `CaptureRow` reading `CAPTURE_STATES` — no page decides for itself what `uploading` looks like. `Shared` is a new route and a new server endpoint. Library filtering, selection and sorting move into a `useLibraryView` hook so the desktop grid, desktop list and mobile list share one state machine.

**Tech Stack:** React 19, TypeScript 5.9, React Router 7, TanStack Query, Tailwind v4 (`@theme inline` over `--sr-*`), `@snaprec/design-system`, Vitest + Testing Library (added in P1 Task 9).

## Global Constraints

Inherited verbatim from `2026-08-08-plate-redesign-roadmap.md` § "Global constraints". Every task's requirements implicitly include that section.

Additional, P3-specific:

- **Management surfaces are light-only.** The rail is the only carbon element on a management page. No `dark:` utilities anywhere in this phase.
- **The breakpoint ladder is exactly four rungs**, from the prototype's RESP scene:
  `≥1280` desktop · `1024–1279` tablet landscape · `768–1023` tablet portrait · `<768` mobile.
- **No page may introduce a card.** `CapturePlate` replaces it.
- **No page may hardcode a status treatment.** Read `CAPTURE_STATES`.
- **Adding a public route touches four files** — `App.tsx`, `prerender.mjs`, `public/sitemap.xml` + `public/_redirects`, `.github/workflows/indexnow.yml`. Missing one ships the page unindexed.
- **Global `ValidationPipe` runs with `whitelist` + `forbidNonWhitelisted`.** Any new request field needs a DTO property; a 400 is the pipe working, not a bug to route around.
- **Entities register in two places** — `app.module.ts` and `data-source.ts`.

import { useSyncExternalStore } from 'react';

/** The four rungs, from the prototype's RESP scene. Every responsive decision
 * in the app reads this — no component carries its own media query, because
 * the grid, the list columns and the touch targets must step together. */
export type Breakpoint = 'mobile' | 'tabletPortrait' | 'tabletLandscape' | 'desktop';

export const BREAKPOINTS: Record<Breakpoint, number> = {
  mobile: 0,
  tabletPortrait: 768,
  tabletLandscape: 1024,
  desktop: 1280,
};

const ORDER: Breakpoint[] = ['desktop', 'tabletLandscape', 'tabletPortrait', 'mobile'];

function current(): Breakpoint {
  const w = typeof window === 'undefined' ? BREAKPOINTS.desktop : window.innerWidth;
  return ORDER.find(bp => w >= BREAKPOINTS[bp]) ?? 'mobile';
}

function subscribe(cb: () => void) {
  window.addEventListener('resize', cb);
  return () => window.removeEventListener('resize', cb);
}

export function useBreakpoint(): Breakpoint {
  return useSyncExternalStore(subscribe, current, () => 'desktop');
}

/** 0 means the grid is abandoned entirely — below 768 the list is the only view.
 * A two-up grid at 390px gives 180px plates with unreadable metadata. */
export function gridColumns(bp: Breakpoint): number {
  return { desktop: 4, tabletLandscape: 3, tabletPortrait: 2, mobile: 0 }[bp];
}

export function rowColumns(bp: Breakpoint): 9 | 7 | 5 {
  return { desktop: 9, tabletLandscape: 7, tabletPortrait: 5, mobile: 5 }[bp] as 9 | 7 | 5;
}

export function touchTarget(bp: Breakpoint): number {
  return { desktop: 32, tabletLandscape: 32, tabletPortrait: 40, mobile: 44 }[bp];
}
```

import { useEffect, useState } from 'react';

/** The four cases from scene H5. The distinction that matters to the user is
 * between "install it" and "it is installed but something is wrong" — those
 * take different actions, so they are different states, not one error. */
export type ExtensionStatus = 'connected' | 'notInstalled' | 'notResponding' | 'unsupported';

export interface ExtensionDetectDeps {
  isChromium: boolean;
  ping: () => Promise<{ version: string } | null>;
  timeoutMs?: number;
}

export async function detectExtension(
  { isChromium, ping, timeoutMs = 1200 }: ExtensionDetectDeps,
): Promise<{ status: ExtensionStatus; version?: string }> {
  if (!isChromium) return { status: 'unsupported' };

  const timeout = new Promise<'timeout'>(resolve => setTimeout(() => resolve('timeout'), timeoutMs));

  try {
    const result = await Promise.race([ping(), timeout]);
    if (result === 'timeout') return { status: 'notResponding' };
    if (result === null) return { status: 'notInstalled' };
    return { status: 'connected', version: result.version };
  } catch {
    return { status: 'notResponding' };
  }
}

const EXTENSION_ID = import.meta.env.VITE_EXTENSION_ID as string | undefined;

function isChromium(): boolean {
  return typeof navigator !== 'undefined' && /Chrome|Chromium|Edg/.test(navigator.userAgent);
}

function ping(): Promise<{ version: string } | null> {
  const runtime = (window as unknown as { chrome?: { runtime?: { sendMessage?: unknown } } }).chrome?.runtime;
  if (!EXTENSION_ID || !runtime?.sendMessage) return Promise.resolve(null);

  return new Promise(resolve => {
    (runtime.sendMessage as (id: string, msg: unknown, cb: (r: unknown) => void) => void)(
      EXTENSION_ID,
      { type: 'PING' },
      (response: unknown) => {
        const v = (response as { version?: string } | undefined)?.version;
        resolve(v ? { version: v } : null);
      },
    );
  });
}

export function useExtensionStatus() {
  const [state, setState] = useState<{ status: ExtensionStatus; version?: string }>({ status: 'notResponding' });

  useEffect(() => {
    let live = true;
    detectExtension({ isChromium: isChromium(), ping }).then(r => { if (live) setState(r); });
    return () => { live = false; };
  }, []);

  return state;
}
```
